# ALRADHY Discovery Fusion (ChatGPT preview)

Independent **single-APK integration** of Gemini's 50 stations (25 history/science and 25 cosmic scale) and ChatGPT's five-scene light-speed story with Fizeau simulator.

- Open the 50-station dashboard as the launcher, then select **🔬 مختبر الضوء** to enter the native lab. Press Back from the lab home to return to the station dashboard.
- Supports TV remote focus/OK, mouse click, Arabic TTS if installed, quizzes with visible questions, and local persistence of the last visited station.
- New Android package ID: `com.alradhy.discoveryfusion`. Distinct launcher artwork. No root or network permission required.
- The 50 Gemini descriptions remain **unreviewed draft content**; fact-check scientific/historical claims before calling it educational release.
- This is a **debug-signed preview**. In-place update guarantees require an enduring private release keystore configured via secure GitHub secrets. Do not delete an installed stable version for this preview.
- One generic animated illustration per subject category does not mean 50 physically correct simulations. The Fizeau lab is the interactive quantitative simulation.

Built on branch `feature/discovery-fusion-chatgpt-v01`; `main` and original laboratory branches remain unchanged.
